# 在线诊断与恢复实施记录

本轮由用户授权同步优化 macOS 与 Windows；代码保留在当前工作区，不自动安装、推送或发布。

## 已接入的行为

- 两端共用原因分类与失败阶段。授权、凭据、身份、权限、超时、连接、协议、内容转换、本机保存和版本变化分别记录；未知错误不默认解释为网络故障。
- 创建恢复分别累计有效核验、失败请求和旧累计次数。授权、网络、限流失败不消耗有效核验；完整核验三次缺失或持续未知协议进入持久暂停。首次原因缺失明确标记，最多保留八条变化历史。
- 独立到期和手动重新核验均只能读取。候选证据不会绑定对象、改名、创建或写正文；后续普通同步必须重新验证，再由原业务日志决定是否继续。
- 同一 canonical 账号在用户私有域共享服务冷却。跨配置、重启和较短新提示不能缩短服务下限；短锁内只做本地状态读写。
- 取消记录来自实际生命周期；无法确定来源时保留写入限制。命名空间操作也保留取消限制，显式继续不清空未知派发证据。
- 目录刷新失败保留旧清单并记录具体原因，成功后退出活跃错误。分享链接沿用原对象归属缓存与身份 CAS，查询失败带链接阶段诊断。
- 界面同时展示本机保存、云端结果、首次/最近原因、阶段和计数。复制诊断使用安全字段白名单，不包含路径、文件名、正文、URL、凭据或账号标识。

## 审查与兼容

独立集成审查指出的七项问题均建立针对性回归并修正：核验准入竞态、业务暂停被覆盖、取消来源缺失、本地读取失败重调度、命名空间取消重放、旧请求重置新周期、图片下载能力被包装层隐藏。核验周期 CAS、具体验证结果与平台边界以 verification.md 为准。

原五分钟新保存节奏、输入 blob、generation、token、写前快照、逐操作验证与原历史均继续使用。正文合并和独立表格定位算法沿用现有实现。
