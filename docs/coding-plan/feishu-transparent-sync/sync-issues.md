# 上传失败的可见提示与处理入口

文件与同步页增加独立的“需要处理”区域，不再将上传失败混同为版本冲突。

状态从同一个挂载 worker 的持久化任务读取，包含文件名、任务 ID、错误代码、本地保存状态、是否属于新建文档及是否可下载。页面显示中文原因、处理步骤和诊断信息；暂时无法查询时保留上次记录并禁用操作，旧 worker 没有任务明细时仍显示挂载级错误。

- 临时网络错误允许重新核验并重试；授权/权限错误引导检查账号。
- unsupported_content 明确说明结构或文档关联问题，下载副本后在飞书原文档应用修改或修正结构，不将重复重试描述为修复。
- 本地副本通过当前挂载和仍未完成的任务 ID 获取不可变捕获内容，不接受任意本地路径；最大 10 MiB，超过大小的文件请在显示的本机文件位置复制保存。副本不会上传、完成、取消或修改任务；Markdown 引用的图片仍保留在挂载目录。
- 保留移除挂载的未完成任务，并标明其来源。

验证：worker 状态包含具体失败文件；副本字节和任务状态不变、拒绝不存在的任务；会话/CSRF 和附件下载；界面处理建议、永久错误不显示无效重试、临时错误重试和过期状态；相关模块全量测试。
