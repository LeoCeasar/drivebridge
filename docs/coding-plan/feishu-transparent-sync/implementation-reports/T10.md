## Implemented experience

Chinese compact file-management tool with system fonts, white/neutral surfaces and blue/cyan accents. Sidebar lists persisted conflicts; status table separates local save from cloud confirmation. Settings has account/authorization, shared folder and mount location steps. No CDN, marketing hero, remote font or rendered Markdown/HTML.

Conflict view shows common base/local/cloud as read-only plain text and an editable result. Server difflib calculates base-relative hunks; each supports local/remote/base selection. Manual result editing locks structural hunk choices until the explicit preserve-and-regenerate action, avoiding silent overwrites of manual edits. Autosave is debounced and serialized; state reports successful local draft saving only after backend acknowledgement. Draft is explicitly saved before Resolve, including stale input cases; 409/offline keeps it. Empty saved draft differs from no draft. Read-only binary conflicts preserve their source copies and cannot be emptied by Later/reset.

First-run settings/auth use the manager without a worker. Existing worker state/conflicts/drafts/resolve go through manager authenticated IPC; UI never opens worker databases. Config replies omit credential/auth-root fields. The recovery authorization action is distinct and sends recovery:true only when clicked. Its button is capability-gated by manager implementing auth.RecoveryGuard; the core manager snapshot safely hides it until the T09 followup guard exists.

`feishu gui [--no-open-browser] [--conflict UUID]` registers on the product Command in gui.go. One current-user host uses a private locked runtime descriptor. A subsequent gui invocation authenticates to that existing host to mint a fresh one-time bootstrap, rather than exposing a reusable browser token. New mounts always start as background workers. Closing host cancels only UI/auth ownership through Manager.Close, never calls worker Stop; mount stop is a separate explicit action.

## HTTP/session security

- Binds TCP4 127.0.0.1 only; exact bound Host and loopback peer checks.
- One-time fragment bootstrap expires in three minutes, is removed from browser history before API use, and exchanges for an HttpOnly, SameSite=Strict, path=/ cookie. Browser sessions expire in eight hours; pending/session counts bounded.
- Every browser mutation requires exact Origin plus session CSRF token, except bootstrap which requires exact Origin and one-time secret. GET foreign origins also denied. No CORS permission is emitted.
- Internal descriptor control requires its private bearer capability and instance nonce, rejects browser Origin and redirects, and returns only a newly minted bootstrap URL. Descriptor/notification state private files use no-symlink checks, fsync, replacement and directory sync.
- CSP disallows external/inline scripts, frames, base/form targets; nosniff, no-referrer and no-store apply to all responses. Embedded static routes are an exact allowlist, not a filesystem server.
- Canonical paths reject traversal, duplicate slashes, backslashes, NUL and encoded paths; route IDs require canonical UUIDs. Methods, JSON type/unknown fields/trailing data and body limits checked. JSON request limit 15 MiB; decoded draft/resolve content limit 10 MiB.
- User source text uses textContent/textarea.value only. JSON uses Go's default HTML escaping. Authorization/source links accept only HTTPS without embedded credentials. HTTP failures return stable Chinese messages/codes, never err.Error/raw CLI output. Status LastError uses a strict known-code allowlist.
- Resolve body is the exact canonical model.ResolveRequest (Content encoded as JSON base64 bytes). URL/body conflict ID and captured generation/revision checked after SaveDraft; backend then performs its own engine recheck. Entry identity stays server-bound, avoiding an untrusted arbitrary target entry.
- Large diff work is bounded: above 2,000 combined lines or 2 MiB combined source, present one conservative whole-document hunk instead of unbounded quadratic matching. This does not truncate source data.

## APIs and composition

```go
func ui.Start(context.Context, ui.Options) (*ui.Host, error)
func (*ui.Host) URL() string
func (*ui.Host) BootstrapURL(model.ConflictID) (string, error)
func (*ui.Host) Close(context.Context) error
func (*ui.Host) PollConflicts(context.Context) error
func (*ui.Host) NotifyConflict(context.Context, model.ConflictID) error
func ui.OpenExisting(context.Context, runtimeDir, configKey string, conflict model.ConflictID) (string, error)
func ui.NewManagerBackend(*manager.Manager) (*ui.ManagerBackend, error)

type Options struct {
    Backend Backend
    RuntimeDir, ConfigKey string
    Notifier Notifier
}
type Backend interface {
    Status(context.Context) (StatusView, error)
    Config(context.Context) (ConfigView, error)
    Configure(context.Context, ConfigRequest) (ConfigView, error)
    AuthStart(context.Context, model.ProfileID) (auth.AuthFlow, error)
    AuthComplete(context.Context, string) error
    Conflict(context.Context, model.ConflictID) (ConflictInputs, error)
    SaveDraft(context.Context, model.ConflictID, []byte) error
    Resolve(context.Context, model.ResolveRequest) error
    Mount(context.Context, model.MountID, string) error
}
// Optional backend capabilities, implemented by ManagerBackend:
// AuthStartRecovery(ctx, ProfileID) (auth.AuthFlow,error)
// ClaimConflictNotification(ctx, ConflictID) (bool,error)
type Notifier interface {
    Available() bool
    Notify(context.Context, string, string) error
    Open(context.Context, string) error
}

func (s *store.Store) ClaimConflictNotification(context.Context, model.ConflictID) (bool, error)
func platform.DesktopAvailable() bool
func platform.Notify(context.Context, title, message string) error
func platform.OpenBrowser(context.Context, string) error
```

Typed exported transport views and requests are in ui/types.go. ConfigView contains sanitized ProfileView/RemoteView/MountView plus can_recover. ConflictInputs is manager-side canonical records/byte inputs; browser ConflictView contains source strings, explicit has_draft, base-relative DiffHunk list and captured generation/revision. No generic arbitrary map/CLI pass-through route exists.

Routes: GET /api/status; GET/POST /api/config; POST /api/auth/start (profile_id, optional recovery); POST /api/auth/complete (flow_id); GET /api/conflicts/{id}; PUT /api/conflicts/{id}/draft; POST /api/conflicts/{id}/resolve; POST /api/mounts/{id}/start|stop; POST/GET /api/session; authenticated private POST /internal/open.

Notification flow: check DesktopAvailable first, then shared durable Store claim (via Manager.ClaimConflictNotification for host, directly for worker). Claim is per ConflictID across revisions/restart, before native side effect. Host also keeps its seen/opened count state; new revision increments count without refocus. No desktop causes no claim/notify/browser; conflict stays durable. Worker OnConflict must notify/spawn same executable `feishu gui --conflict <UUID>` with configured root flags so a closed UI host does not suppress future conflict notification. T09 owner was sent exact argv/API and shared-claim requirement. Native notification errors do not remove conflict data.
