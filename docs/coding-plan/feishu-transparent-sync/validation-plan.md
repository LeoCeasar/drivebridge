# 飞书透明同步：接口验证清单

状态：首次接口实验已完成，记录于 validation-results.md；发现原方案的并发安全假设不成立。本文不是正式开发文档或全部验证通过的报告。

## 环境与作用范围

- 使用一个单独的飞书测试文件夹和可授权的测试账号。
- 不在聊天、日志或报告中记录 app secret、访问令牌、刷新令牌或原始凭据目录。
- 先固定 lark-cli 版本及其匹配的文档/源码；确认命令帮助、身份和 scopes 后才调用。
- 使用专门子目录，最多新建 3 篇在线文档和 1 个普通测试文件；内容全部为合成数据。
- 只读写本次创建并记录 Token 的测试资源；不修改现有业务资源、成员权限或所有权。
- 验证结束保留资源以便复查；不自动删除。CLI、账号授权及首次接口实验已完成，结果有满足项、不满足项和未覆盖项。

## 后续本地验证

以下为设计需要覆盖的场景，不等于已经具备实现或测试已通过：

- AI truncate 后分批写入、编辑器临时文件 rename 保存、空文件和 UTF-8 特殊字符。
- 上传等待期间再次保存、合并时再次保存、远端更新与本地未关闭句柄同时存在。
- 崩溃恢复、权限撤销、网络中断、磁盘满、升级后保留基线和待上传内容。
- 三方 diff 以共同原版/本地/云端构造可编辑结果；合并窗口关闭不丢数据；提交时任一输入版本变化则重新核验。
- 桌面环境弹窗与合并界面；纯 CLI/无桌面环境保留冲突和可查询状态。
- 两台电脑和两个系统用户分别完成首次配置；配置路径动态确定；不同 profile 的身份、目录、缓存与待上传记录不混用；安装包和仓库不携带实验凭据及固定测试目录。
