# 挂载移除、Markdown 可读性和构建版本

用户确认：有未同步内容时阻止删除，并提供处理入口。移除不删除飞书云端文件，也不删除账号 Git 历史。

## 实施边界

1. 新的“删除挂载”会安全停止实例、检查未上传/冲突/命名空间及 VFS 状态。发现未完成内容时保留配置和数据，返回可处理的原因；界面提供启动同步、恢复并启动、冲突处理或历史归档入口。
2. 可删除时确保现有历史输入已归档，再移除配置、所有权记录、正文/VFS 缓存及实例日志。只操作程序拥有的状态目录；挂载点只删除空目录，不递归删除挂载点或用户目录。账号盘保留轻量的“用户已取消”意图，避免扫描后自动重建。
3. 保留旧 archive/restore API 兼容已有配置；新的移除入口不再仅标记 archived。旧归档记录可从管理页明确恢复并启动，或在满足清理条件后彻底移除。
4. 在线文档仍投影为 Markdown。本轮验证转换是否累加转义；不改变当前投影版本的编码规则，不批量删除用户文件中的反斜杠。Markdown 源码仍含保守标点转义；渲染显示与原始源码是两个层面。恢复 Git 版本保留该版本的原始字节。
5. 新建 `.md` 沿用当前在线文档策略；已有普通 `.md` 保留普通文件身份。此次不暗中改变上传类型，也不把在线文档替换成另一资源。
6. 使用 `drivebridge_feishu` 编译标签分离注册表。无标签仍为完整 Rclone；飞书构建仅注册产品命令、必要挂载命令、配置/版本及 Feishu/local 后端，保留运行同步/合并/历史所需组件。打包入口显式选择 feishu/full，清单记录版本。

## 验证

- 管理器：干净挂载确实移除配置与缓存；未上传/冲突/打开文件阻止删除；保留云端/账号 Git 历史；重扫不复活；失败不删除用户路径。
- 转换器：路径、版本号、标点不冗余转义；实体、反斜杠、代码、列表、链接与表格往返语义保持。
- UI：提示有直接处理按钮；删除失败保留内容并说明原因；成功刷新列表，不要求用户先找归档位置。
- 构建：两种注册表分别编译；飞书依赖列表不包含 S3/Drive/Dropbox 等后端；比较相同平台和链接参数的实际二进制大小，不根据名称推测精简成功。
