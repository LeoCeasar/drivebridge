# macOS 真机验收记录

2026-11-12，当前用户的 Apple Silicon Mac。使用正式 DMG 图形安装入口，复用原有飞书授权和 macFUSE kernel 驱动。仅修改本轮新建的验收文件，没有修改用户已有文档。

## 真机发现并修复的问题

1. **schema 1 升级被拦截。** 0.2.1 安装器的维护校验只接受 schema 2，缺少历史桶的旧数据被误判损坏。修复为安装前按已知旧 schema 只读校验，首次正常启动时迁移；未知 schema 和缺失正文仍拒绝。已验证只读校验前后数据库字节一致。
2. **段内换行导致云端确认失败。** 飞书 XML 接口去掉文本中的字面换行，使两个英文词连在一起。Markdown 软换行现在转为空格，硬换行仍使用 `<br/>`，本地历史保留原始字节。
3. **单边编辑并插入段落误报冲突。** 仅在本地基线与云端正文、块身份一致，且有稳定前缀锚点、目标唯一、全部内容受支持时，逐步修改并回读确认。无锚点的整篇重写、重复身份、复杂不可编辑块及双边歧义仍保留保护。
4. **重复刷新产生无效历史。** 空资源映射在持久化后变为 nil，与新建空 map 比较不一致；冲突的 entry/metadata 写入还会短暂丢失冲突上下文。统一空映射并保留当前冲突引用，重复保存/刷新不再生成新版本。

上述问题均有失败复现及修复后的测试。相关日志保留于 `.superpowers/global-git-history-implementation/real-machine/`，包含合成样本和本机账号数据，不提交该目录。
