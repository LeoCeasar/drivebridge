# 账号盘与目录发现使用说明

> **当前方案（2026-11-11）：** 应用自有登录窗口、无需浏览器扩展。macOS 14+ 正式 provider 已接入；范围与实机证据见 [应用自有登录设计](owned-login-design.md) 和 [验证记录](owned-login-verification.md)。

本文对应本次实现的源码行为。自动发现负责收集目录入口；文件内容读取、同步和写回继续使用账号的官方 CLI 授权。

## 首次设置

本轮正式接入采用 **macOS 14 及以上的应用自有 WKWebView 登录窗口**。安装包内含 `libexec/DriveBridge Session.app`，不要求 Chrome/Edge/Safari、浏览器扩展或 Native Messaging 注册。Windows/Linux 保留现有 CLI 与同步功能，但此应用内网页登录当前不可用。

1. 安装包含桌面、挂载引擎和原生登录 helper 的完整 macOS 包，启动 DriveBridge 并打开管理页。完整目录需保持在一起；不要单独移动主 `.app` 或 `libexec` 中的登录 app。
2. 添加账号并完成官方 CLI 用户授权。官方 API 授权与云盘网页登录分别管理；官方授权流程必要时仍可打开系统浏览器，但不读取该浏览器的 Cookie。
3. 在“账号盘与自动目录发现”中选择账号。企业云文档地址可留空，由账号识别；需要指定时填写自己租户的 HTTPS 云文档地址。
4. 点击“打开应用登录窗口”。应用打开自有原生登录窗口并展示真实地址。请在该窗口亲自完成飞书登录或企业要求的验证，确认登录的是刚才官方 CLI 授权的同一账号。
5. 登录后程序自动核验当前个人入口归属，并扫描个人、可见共享和隐藏共享入口的分页；如等待较久，可点击“我已登录，重新验证”。本次完成后，原生窗口显示本机登录完成结果，云盘网页视图隐藏，账号盘创建或复用并启动挂载。若仍显示部分完成、需要登录或 helper 不可用，应先处理状态再重试；配置保存不等于已经挂载。
6. 账号盘内显示“个人目录”“共享目录”“手动添加”。个人目录同时保留官方个人根目录中的普通文件；目录内部继续按真实云端目录读取。

登录窗口只承担认证与目录发现。已验证原型曾出现云盘正文空白或加载骨架，因此不把它作为完整云盘浏览器；主功能仍在本机管理页。Cookie 由 WebKit 保存在应用自有、按 OS 用户及产品账号隔离的会话中，不导出到配置，不导入日常浏览器会话。目录响应只包含入口和个人资源归属核验元数据，文件正文与写回使用官方 CLI。

关闭登录窗口表示隐藏，不表示退出账号，托盘运行时仍可按需请求目录。会话过期、MFA 或企业策略要求重新验证时，需要主动重新打开登录窗口；不承诺永久免登录。本机开发载荷的实际验证结果见[原型与正式验证范围](owned-login-verification.md)。

## 补录新增或未见目录

管理页提供两种补录入口，均先用当前账号的官方 CLI 核验目录，然后保存入口：

- **按名称查找：** 输入目录名称，查询文本最多 30 个字符。点击“搜索目录”，核对候选目录，再选择“添加”。名称相同的候选可能对应不同目录，应核对候选标识。
- **按链接或标识补录：** 粘贴有权访问的文件夹链接或文件夹 token，点击“核验并添加目录”。

补录用于把已有云端目录加入账号清单。补录成功后，已运行的账号盘会收到目录刷新请求。它不会在云端新建或重命名目录。

同一个 token 只建立一个可写路径。首次建立入口映射时优先使用个人目录，其次共享目录，最后手动添加；同一目录的个人、可见共享、隐藏共享、手动补录来源仍会在管理页保留。既有路径在后续扫描中保持稳定，因此重复添加同一资源不会再建立另一份可写入口。

账号根、分类入口及已登记的目录根受到保护，不能直接重命名或删除。可在真实个人根目录或真实目录内部创建和编辑受支持的子项；账号根、“共享目录”“手动添加”分类本身不是真实云端父目录，不能直接向其中创建文件或目录。

## 重新扫描与后台刷新

- 在管理页选择账号后点击“重新扫描”，可立即请求更新入口清单。
- 托盘“账号与目录发现”显示各账号的网页登录状态、发现状态和最近扫描时间，并提供“重新扫描目录”。需要重新登录、正在处理或未启用发现时，该动作不可用；可通过“管理账号与网页登录”返回管理页处理。
- 桌面程序成功取得桌面实例所有权后，启动一个随桌面生命周期运行的发现任务。它首次约 10 秒后检查，随后每 5 分钟检查一次；对已启用、已配置、无需重新登录且距上次扫描达到 5 分钟的账号执行刷新。
- 关闭日常 Chrome/Edge/Safari 不影响此原生会话。关闭应用登录窗口只隐藏它；退出桌面或会话失效后，不据此删除目录和待上传数据。官方 CLI 同步仍由独立 worker 按既有状态运行。
- 后台发现只刷新目录清单，不会启动用户已停止的同步挂载。退出桌面托盘后，该后台发现任务停止；已有同步进程按原有桌面退出行为继续运行。

扫描失败、会话过期、分页异常或某次入口消失，都不会据此删除旧清单和已有路径。界面会保留旧数据并显示相应状态；旧入口仍在清单中不代表云端权限仍然有效。

## 发现范围与当前限制

“本次扫描完成”表示个人入口、可见共享入口和隐藏共享入口三路分页完成。它不能证明已递归扫描所有子目录，也不能证明已列出所有通过链接可访问的目录；未出现的目录可通过名称查找或链接补录。

扫描器每次都用当前个人入口的账号归属核验网页登录身份。个人目录入口为空时，会再检查当前个人资源入口的第一页；只有至少存在一个可验证对象，且该页列表中的对象均属于当前授权用户，才继续共享扫描。这些资源仅用于身份核验，不会加入目录清单。个人目录和该资源页都为空时，保持身份未确认并保留旧清单；历史快照不能替代本次身份核验。

网页发现依赖当前租户网页接口的响应结构。身份不符、会话失效或不支持的响应会显示为需处理状态，保留已有入口；请使用对应账号重新网页登录或补录可验证的目录。

## 验证证据的范围

macOS WKWebView **原型**已实际完成官方页面登录、账号归属核对、3 个个人＋3 个可见共享＋7 个隐藏共享来源关系的读取（去重 12 个入口），以及隐藏窗口、helper 重启、完整验证程序重启后的新读取和独立存储隔离。详见[原型验证记录](owned-login-verification.md)。这些结果没有被记成正式安装 App 的验收通过。

正式源码接入、打包检查、模块测试和跨平台编译只证明各自覆盖的场景。正式安装包内的登录、关闭窗口继续扫描、应用重启复用、账号隔离、退出清理和账号盘联调结果仍待填；签名公证、Windows/Linux 原生登录与原生运行没有新增通过结论。Windows/Linux 当前提供“登录不可用”，而非要求一个不存在的 helper。

既有官方 CLI 与网页响应结构的只读证据仍保留，见[接口范围](shared-discovery-boundary.md)和[脱敏目录核验记录](evidence/2026-11-11/discovery-verification.json)。本轮原型没有上传、覆盖、删除或挂载操作，也不证明所有子树或任意共享链接全集。操作手册保留真实原型截图，正式流程的结果单独标记待验收，不补造截图。
