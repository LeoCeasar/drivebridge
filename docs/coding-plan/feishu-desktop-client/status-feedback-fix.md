# 管理页重复“无法复核云端内容”提示修复

2026-11-11，基于 `a9350ea28`。

## 原因与复现

`/api/status` 每5秒聚合读取全部挂载的本机状态与冲突摘要，不做云端正文核验。停用挂载的数据库需要取得本机所有权锁；多个页面、管理进程或托盘的状态查询可能发生短暂竞争。旧适配器只要其中一个挂载读取失败，就让整页状态失败；通用错误映射又把它显示为“暂时无法复核云端内容，草稿已保留”。这条文案不能据此判断飞书断网或草稿保存失败。

本机用6个并发CLI状态查询复现：6次均返回 `pending`（退出码6）。没有对云端文件执行修改。

## 改动

- 每个管理服务保留每个挂载最近一次完整状态及冲突摘要。单挂载暂时繁忙不再使整页失败，也不会清空已有冲突列表。
- 缓存明确标记为上次结果并显示时间；没有历史数据时显示等待核对，不伪造“已确认”或零冲突，暂不使用旧状态执行启动/停止等操作。
- 同服务并发状态读取复用当前结果；页面刷新只保留一个在途请求。后台失败使用轻量连接状态，重试间隔为10、20、30秒，恢复后回到5秒。
- 主动刷新失败使用本机状态文案；后台轮询不覆盖用户操作或草稿保存提示。
- 本机忙、账号需要授权、身份变化、挂载服务不可用分别标识。真实冲突提交仍必须通过原有版本与云端新鲜度核验；本机草稿、上传日志及冲突恢复数据的保护不变。
- CLI状态保持严格失败语义，避免自动化把不完整数据当作完整结果；以上容错作用于管理页观察。
