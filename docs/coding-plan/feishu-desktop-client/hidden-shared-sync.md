# 隐藏共享文件夹同步开关

2026-11-11；用户确认指飞书中被隐藏的共享文件夹，不是点号开头目录。

## 约定

每账号独立保存开关，默认开启、旧配置兼容。关闭后：仅来源于隐藏共享的目录入口在账号盘中隐藏，不再后台扫描其子目录、刷新正文或派发新的上传和命名空间操作。个人、可见共享及手动添加等明确入口不受影响；同一资源去重后有这些入口则继续可用。关闭不是云端删除，不删除本机缓存、待上传任务、冲突或草稿，重新开启后继续。已经在执行的网络请求可能完成；打开/脏 VFS 节点优先保护，可能在关闭文件前暂时保留显示。普通独立挂载不受账号盘开关影响。

持久目录记录不能用缺失/过滤模拟云端删除：原始发现快照及 Store 元数据保留，展示过滤与同步调度独立。手动补录的明确意图优先于隐藏共享来源。

## 实施接口

- discoverySettings.SyncHiddenShared *bool，nil=开启；DiscoveryView.SyncHiddenShared bool 返回有效值。
- Manager.SetHiddenSharedSync(ctx, profileID, enabled) (DiscoveryView,error)：按账号操作锁持久保存、通知运行的账号盘刷新；不得启动已停或已归档挂载，不要求重新登录。
- overlay.AccountOptions.SyncHiddenShared func(context.Context)(bool,error)：nil=开启，读取当前账号偏好并校验原绑定；应用无需重新挂载。
- discovery.HiddenSharedOnly(Entry) bool：含 shared_hidden，且无 personal/shared_visible/manual 或显式 Manual，Placement=personal 也不隐藏。
- discovery.ScanWithOptions(..., ScanOptions{ExcludeHiddenShared:...})：关闭时不请求隐藏共享来源，旧扫描API默认包含全部；原有快照保留。
- POST /api/discovery/{profile}/hidden-sync，body {enabled:boolean}，沿用会话/Origin/CSRF，缺字段/错误类型拒绝。
- UI 账号与目录增加勾选框“同步飞书中隐藏的共享文件夹”，即时保存，有忙碌/失败回滚、多账号状态隔离及说明。
- Overlay.SyncPathAllowed(ctx, remote) (bool,error)、SyncEntryAllowed(ctx,id)：用保留快照中隐藏专有入口 Token 找到已映射根路径，对后代按路径边界过滤。
- Fs.List 过滤持久清单；目录刷新/预热跳过被停用子树，冷正文物化不请求远端；现有本机内容/恢复数据保留。
- ShouldSync 与 ShouldRefresh 组合开关；namespace 调度新增可选 ShouldSyncPath，所有源/目标路径均核对，暂停任务不确认删除或丢弃。已在途的命名空间记录保留，重新开启后可继续观察/核对。

## 使用与实现说明

在“账号与目录”选择账号，勾选或取消“同步飞书中隐藏的共享文件夹”，立即保存到当前系统用户的账号配置，不需要重新登录或重挂载。原始入口清单保留用于恢复，页面中的“已暂停同步”与目录是否存在于保留清单分开表示。关闭后新的扫描不请求隐藏共享来源；个人与可见共享继续扫描。

目录的显示名称可能经过编码或同名去重，因此暂停根通过 Token 查找已有映射路径，按路径分隔边界匹配后代，避免误停同名前缀目录。手动添加的子目录若复用隐藏入口作为规范根，会保留必要的规范根，避免明确添加的目录失去既有路径。暂停不是权限撤销；已经打开或本机缓存中的内容可能仍可读取。

显示、目录预热、正文刷新、内容上传与创建/重命名/删除调度均使用当前设置。关闭前已开始的请求可能完成，结果不明的日志保留，不把暂停当作完成。重新开启后按原日志继续，用户已有冲突仍需要明确处理。其他单独创建的共享目录挂载沿用其自身启动/停止配置。
