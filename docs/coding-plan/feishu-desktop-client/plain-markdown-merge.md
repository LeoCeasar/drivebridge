# 普通 Markdown 文件三方同步实施计划

2026-11-11；基于用户已确认的 B（上次同步基准）、L（本地修改）、R（当前云端）规则。

目标：普通云盘 `.md` 文件拥有安全三方合并；在线文档逻辑不变，其他文件维持已有覆盖策略。

## 规则与边界

- `.md` 不区分大小写，以普通文件的云端名称（缺失时用挂载路径）识别，不把所有文本或二进制文件改为合并。
- R=L 确认；R=B 上传 L；L=B 接受 R；双方独立修改合并后上传，重叠且不相同的修改保留冲突。
- 基准、云端备份、原始本地内容和实际合并上传内容分别保存；内容哈希而非修改时间用于判断。
- UTF-8 Markdown 不限制为在线文档支持的语法，保留原换行与无末尾换行；非文本、过大、复杂或缺失基准时不猜测、不覆盖。
- 上传前二次下载复核，变化时重新规划，连续三次变化转冲突；上传后回读验证目标正文。
- 已持久化上传计划的结果不明时只观察核对，不盲目重传；核对 journal.Desired，而非只核对原本地正文。
- 上传期间接受的新一代本地写入不能丢失；旧任务确认时保持该任务的本地基准与云端基准配对，后续任务再次三方合并。
- 人工 diff 页复用现有草稿、刷新、提交与导出流程；普通文件的冲突版本键为 sha256:<正文哈希>，不是伪造服务端 revision。提交前核对最新云端和本地 generation。
- 正式接口没有 CAS，缩小检查/写入窗口并保留备份，不宣称绝对原子协同。

## 实现与使用说明

普通 `.md` 以文本方式三方合并，不走飞书在线文档 XML 解析，任意 Markdown 语法都可保留。双方编辑不同位置时自动组合；同一区域相同修改去重，不同修改进入已有合并队列。不会把 `<<<<<<<` 等冲突标记自动写入用户正文。当前文本编辑边界为有效 UTF-8、无 NUL、每份输入与合并输出均不超过 10 MiB。超大或复杂差异、缺失基准、不支持的字节会保守保留冲突，二进制/超大正文可导出副本；不冒险覆盖。

用户无需开启新设置。在挂载目录正常编辑普通 `.md` 即可。需要人工处理时，打开“冲突与合并”，查看基准、本地、云端差异，编辑结果并提交。提交先重新核验云端内容和本地版本；如果期间又有变化，保留草稿并要求刷新。成功接受后排队上传，只有回读验证并发布成功才显示已同步。

`sync/file.go` 对实际上传目标使用持久 `journal.Desired`。自动合并后的上传内容可能同时包含他人的修改，与原本地保存不完全相同；进程重启时必须核对这个合并目标。新保存若在旧上传过程中被接受，旧确认保留旧任务的本地基准，再用新保存与最新云端重新合并，不能拿云端基准直接替换新保存的编辑来源。

## 验证记录

- Markdown 合并：单边/相同/独立行/同一行独立位置、冲突插入删除、Unicode/CRLF/末尾换行、6000 行稀疏改动、输入/输出增长限制；定向 race 与短时 fuzz（197215 次执行）通过。
- Sync：本地单边直传、远端单边采用、独立编辑合并、`.MD`、其他文件覆盖回归、二次观察变化重算、三次漂移保留冲突、合并上传后断网/重开只核对不重传、旧上传期间新保存保留、不把原 L 误认为合并上传成功、缺失基准/非法文本不覆盖。
- 人工解决：实际快照哈希、Token 与 generation 校验、失败保留草稿、刷新期间新草稿/新保存保护、超限和非 MD 拒绝。
- 实际 HTTP/Store/Engine/Overlay/VFS 集成：普通 MD 独立修改自动合并发布；冲突 diff 有内容、过期提交 409 保留草稿、有效提交接受后再上传并发布，保留原文件 Token。
- 真实 macFUSE kernel 隔离挂载：冷读取、OS 文件写入、合并后 38 字节完整读回、重叠冲突及人工解决后 47 字节完整读回通过。远端为合成数据源，不是实际飞书协作写入。测试卷已卸载。
- Bridge/Feishu/Desktop 相关测试通过；Markdown/Store/Sync/Integration/UI race 通过，12 个前端测试通过；macOS 原生构建、Windows cmount CLI 和 Linux amd64 CLI 交叉构建通过。交叉构建不等同原生平台验收。

飞书远端最后检查与写入之间仍无 CAS，二次观察只能缩小竞争窗口；读取或结果不明时保留待处理记录，不盲目重放覆盖。当前不承诺每次 grep 搜索前都复核远端最新正文，也不改变后缀过滤和按需下载策略。

本机已安装候选二进制并核对 SHA-256 一致；219 个受保护文件升级前后无变化，13 个历史待处理任务与 5 个冲突保留。按当前保存的启动意图，账号盘正常运行，已停止的其他挂载没有被重新启用。
