# 挂载管理、后台拉取过滤与 AI 搜索

2026-11-11；对应需求：管理页移除不需要的挂载，后缀规则可编辑，AI 使用 grep 按需读取。

## 用户操作

在“文件与同步”中，每个挂载提供“停止同步”和“移除挂载”。停止保留主列表配置；移除安全停止后归档配置，主列表隐藏该项。飞书文件不会被删除，本机缓存、已持久化待上传任务及冲突副本保留。

“已移除挂载（本机数据保留）”中可恢复配置。恢复后保持停止，需明确启动才会恢复上传。账号扫描、登录和后台重启不会自动复活已移除配置。存在打开文件、尚未落盘写入或卸载失败时拒绝移除，提示关闭文件并等待本机写入。

在设置的“后台拉取过滤（可选）”中选择挂载并编辑后缀输入框，默认 `.log, .db`。支持逗号、分号或空白分隔，例如 `.log, .db, .sqlite`；不区分大小写，自动补点、去重。只接受单个扩展名，不接受路径、通配符或多段后缀。留空保存表示关闭过滤，而不是恢复默认值。

规则保存后无需重新挂载，下一次后台检查使用新规则；已经开始的读取可能完成。文件名仍在目录中可见。过滤仅跳过后台正文刷新；主动打开、grep、上传回读核验和冲突保护不受影响。本机创建、修改这些文件仍会上传。

## AI 搜索的实际行为

仅枚举文件名、目录或 stat 不要求下载正文；内容搜索会触发实际读取，尚无本机正文的文件按需下载。当前实现首次读取整文件，不是远程分块搜索。再次读取可复用缓存，缓存释放后再次下载。

本地尚未上传的修改，grep 读取本机内容；搜索不会代替写回任务，也不代表云端已经确认。上传继续按挂载写回策略处理。慢速已读文件后台刷新与上传循环分开运行，单个刷新不再拖住其他文件上传；刷新单工作线程逐个完成快照，退出时取消并等待读取结束。

`rg` 默认跳过隐藏文件及忽略规则命中的文件。需要扩大范围时可使用：

```sh
rg --hidden --no-ignore '关键词' /实际挂载目录
```

这仍受账号权限、目录发现范围、网络和文件类型限制；读取失败会报错，不能当作内容为空。遍历整个云盘搜索正文可能下载大量文件，消耗带宽和缓存。后缀过滤不是禁止 AI 主动读取的权限策略。

## 接口与数据边界

- `POST /api/mounts/{id}/archive`：安全停止并归档，仅影响本机配置。
- `POST /api/mounts/{id}/restore`：恢复可见配置，不启动。
- `POST /api/config`，`action=mount_policy`、`mount_id`、`background_pull_excluded_extensions`：保存规则，显式空数组关闭过滤。
- CLI：`feishu mount remove NAME`、`restore NAME`、`pull-policy NAME --exclude .log,.db,.sqlite`；`--exclude=` 关闭过滤。
- 旧配置字段缺失使用默认值，新配置显式空数组保持关闭。所有管理请求沿用会话、Origin 与 CSRF 校验。

Bridge、Feishu、Desktop 相关 Go 测试及 12 个前端测试通过。回归覆盖归档保留 13 个待处理任务和 5 个冲突、恢复不启动、重复恢复不覆盖新启动意图、显式空过滤规则、过滤文件本地创建与更新上传，以及慢刷新期间其他任务继续上传。
