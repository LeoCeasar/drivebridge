# 后台字符串转换验收

2026-11-13；macOS arm64 开发版 0.2.15；实现源码 `ff0e47c5a`。

- 替换仅在后台合并、创建在线文档和写回处理副本；前台打开、输入、保存及 VFS 保存路径没有新增转换或网络步骤。五分钟同步周期不变，原始正文与冲突捕获仍留在 Git 历史中。
- JSON 支持 source/target、literal 精确普通字符串及 HTML token 转换；用户配置无固定条数上限，保留文件与单条长度资源边界。代码、链接、图片、转义及富 HTML 区域不会被全局字符串替换穿透。
- 初始化在实际 config.json 旁边原子生成 conversion-rules.json，已有文件不覆盖。默认只有已确认的 br 兼容规则：段落换行、表格 `; `，覆盖 `<br>`、`<br/>`、`<br />` 和大小写变体。不默认删除未确认有问题的字符。
- 旧草稿与正文只有规范化或编码等价差异时，可恢复自动同步；事务仍校验完整捕获、当前代际及未知操作日志。存在实质正文差异时不自动覆盖草稿。
- 替换结果必须稳定且有界。直接连锁规则在加载时拒绝；由上下文拼接形成的不稳定匹配在后台停止写回。
