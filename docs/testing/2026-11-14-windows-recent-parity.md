## 原生验证中发现并处理的问题

第一轮 [43466530711](https://github.com/LeoCeasar/drivebridge/actions/runs/43466530711) 没有通过，未生成安装包。

- 配置读取缺少 Windows `FILE_SHARE_DELETE`，并发替换时出现共享冲突。读取改用共享删除句柄；配置与转换规则使用限定同目录的 `ReplaceSharedFile`，Windows 请求 POSIX rename，普通 `ReplaceFile` 的其他调用保持原状。临时正文先同步；拒绝替换时保留完整旧文件。
- 合并请求的内部超时先于草稿落盘启动，慢盘可能在保存前耗尽预算。现先保存草稿，再开始云端核验预算；调用方取消仍然有效。
- 图片 CLI 测试夹具误以为 Windows 的合成权限位等同 Unix 权限，正常/身份/取消测试在初始化阶段退出。修复平台判断并强化错误类型断言，增加已产生部分文件后的取消验证。
- 测试把 Windows 故意保持不存在的挂载入口当成已创建目录；现在明确创建用户目录后再测试移除挂载不会删除用户内容。
- 调度隔离测试取消不适用的“一秒磁盘速度”限制，以被阻塞文件的显式屏障证明其他文件可完成。
- 旧集成测试仍要求“仅本地整篇改写”人工合并；现分别覆盖干净改写自动同步，以及云端同时改写时保留冲突并人工恢复。
