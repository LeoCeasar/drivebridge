## 安装与边界

- [0.2.30 发布页](https://github.com/LeoCeasar/drivebridge/releases/tag/drivebridge-v0.2.30) 中提供完整 ZIP、EXE、MSI。
- Explorer 单选菜单由 EXE/MSI 当前用户安装器注册；便携 ZIP 不自动写注册表。Windows 11 通常从“显示更多选项”进入。
- EXE/MSI 继续要求配套 upgrade.ps1、PowerShell 7+ 与安装协调锁，不能直接双击；现有卸载保护保留。外部 WinFsp、Edge WebView2 Runtime 依赖不由应用自动安装。
- 未签名预发布，未声称人工 Explorer 交互、真实账号登录、安装器升级或正式签名验收完成。原 payload manifest 的未验证标记保留。
- 本轮不发布 macOS/Linux，不改动本机 macOS 安装。
