# 后台自动替换设置入口验收

日期：2026-11-13。macOS arm64 本机版本 0.2.16，实现源码 `c6f2168c5`。

- 入口：托盘/菜单栏 → 打开管理页 → 账号与目录 → 顶部“后台自动替换”卡片。
- 支持原始字符串、目标文本/换行/删除、作用位置、匹配方式、新增/移除自定义规则、保存、重新读取及 JSON 预览。保存不会在操作中途替换运行中的规则；需要重启时明确提示。
- 保存先验证配置，锁内校验磁盘 SHA256 修订，再以私有权限原子替换。非法或过期修订不覆盖现有文件；编辑器保留失败草稿，重新读取时保护未保存输入。
- 新规则默认是可编辑的文本目标；空文本必须显式选择删除才能提交。状态轮询和普通输入不重建正在编辑的规则行。
