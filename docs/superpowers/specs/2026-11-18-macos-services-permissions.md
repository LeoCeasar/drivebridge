# macOS 服务重复与文件操作权限排查

用户要求修复 Finder 重复的复制飞书分享链接菜单，并减少删除、移动时的管理员密码或 Touch ID 提示。

## 设计

DMG 外层 app 不再声明 NSServices，保留 payload app 为唯一提供者，兼容 pkg/便携布局。正常启动时通过 LaunchServices 强制刷新当前 app 和内层 app 的注册，再刷新服务。只有声明服务的 app 设置 servicesProvider。保留 payload 原始字节、签名及 manifest。

升级前捕获属于本安装的旧 Swift 启动器身份，成功替换后正常退出这些进程，并在安装 worker 内刷新注册，不依赖“安装完成后打开”选项。按 bundle 路径、标识、可执行文件三者匹配，不影响其他安装或 Go 后台。新外层启动器启动 Go 后退出，内层服务继续驻留。

管理员验证须先复现：当前用户拥有挂载目录及文件，测试文件重命名成功，删除触发立即删除确认而非管理员验证。不得通过 root 运行、sudo 免密或全盘权限掩盖不支持的操作。等待具体触发项目后定位根因。

## 验收

整个安装应用递归恰有一个复制链接服务，payload 字节完整，pkg 服务继续存在。升级后 Finder 显示一个入口，单选可复制对应 URL，失败不改剪贴板。仅操作自建测试数据，不删除用户文件。
