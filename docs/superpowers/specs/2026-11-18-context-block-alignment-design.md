# 按上下文定位独立内容块

用户已明确要求修复算法。相同内容的表格是独立对象，不能要求用户删表或修改文字来绕过定位错误。现有错误提示和未提交的分享链接、删除恢复改动均保留。

## 方案

沿用 Markdown/云端投影及每次写入后的回读校验。将全篇重复内容拒绝改为上下文分区：先寻找两侧均唯一且顺序一致的未修改内容块作锚点，递归/迭代处理锚点之间的范围；只在范围内建立唯一对应关系。相同完整序列保持原 ID 顺序；纯文本范围继续仅允许有依据的单块修改，投影范围继续沿用唯一最小编辑路径。匹配结果指向当前云端 ID。

保留跨区移动、重排、无锚点重复增减、受保护资源和样式、并发更新及未知写入的安全边界。已确认没有变更的相同表格不产生写入。复杂度有总预算，不因分区产生无限递归或多个超大矩阵。此修复直接进入核心匹配器，不增加需要用户配置的新格式模板。

## 取舍

- 选择上下文约束的匹配：保留 ID 和编辑意图，符合本次台账的唯一分区证据。
- 不选择遇到重复就按出现序号猜配：无法区分移动和删除。
- 不选择整篇删除重建：会丢失独立对象、样式或资源，扩大风险。

## 验收

同文表格分处不同章节可独立修改/删除；重复标题可由上级或相邻唯一内容区分；不改动的同文表格零写入。没有足够依据或跨区移动时不生成猜测操作。用真实问题的私有快照完整离线回放，再在维护升级后正常重试，保留最新本地内容并核验同步结果。
