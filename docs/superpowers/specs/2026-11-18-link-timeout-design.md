# 首次链接补齐超时修复

0.2.28 实测当前 HTML 缺少 SourceURLToken 绑定与 fallback 缓存，3 秒预算两次以约 3020/3022ms 失败，第三次 2265ms 成功并写回，之后五次 19–20ms 命中缓存。对照已缓存文档八次全部 19–28ms 成功。另一未缓存文件使用 12 秒诊断预算，4349ms 成功。

保留 3 秒 Services 握手，后台 CLI 请求预算改为 15 秒，Swift 原生兜底 20 秒（另有有限退出清理时间）。后台依旧异步，不增加 Finder 同步等待，不修改缓存身份校验，不删除数据或重置授权。

首次在线补齐预算耗尽使用独立 link_lookup_timeout 错误，可重试；保留底层错误供代码判断。原生记录请求耗时、结果代码和缓存命中，不记录路径、token、URL 或凭据。首次补齐成功继续条件写回缓存。

验收：模拟耗时 6 秒的首次补齐成功，超过显式测试截止仍清理进程；缓存及剪贴板保护测试保持通过；原预算超时能与其他网络错误区分；本机安全升级并确认后台及缓存正常。
