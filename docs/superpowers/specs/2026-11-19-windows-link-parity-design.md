# Windows 飞书链接体验对齐

用户授权：按上一轮列明的 Windows 差异开始对齐，继续现有未提交功能分支，不提交、推送或发布。

## 行为

- 保持现有文件/目录单选 Explorer 入口、共用链接缓存、身份校验和 20 秒查询预算。
- 成功复制保持静默；错误提示约 6 秒后自动消失，不激活窗口、不阻塞 Explorer、不打开外部程序。
- `--copy` 在创建 Manager 前记录剪贴板序号。在独占打开剪贴板之后重新比较序号，再决定写入。查询期间剪贴板变化则保留新内容并提示重试。
- 获取序号失败、锁超时、取消、无效链接均不清空剪贴板。写入前先分配、填充 Unicode 内存，尽量缩小清空与提交之间的窗口。
- 仅 Windows 改用带序号保护的 Win32 写入；macOS Finder 原生服务及其他平台行为保留。

## 实现选择

采用 Win32 原生剪贴板及无激活短暂提示窗口，复用现有 Go/x/sys 依赖。Toast 受通知设置影响且可能可点击；MessageBox 要求用户关闭；PowerShell/WinForms 会引入额外进程和启动延迟，因此不用于本入口。

剪贴板序号比较与提交必须位于同一次 OpenClipboard/CloseClipboard 中，避免先检查再调用外部库写入的竞争。创建隐藏的所有者窗口并在同一 OS 线程上打开、写入和关闭剪贴板。

## 验收与边界

共用逻辑回归覆盖查询开始前捕获、查询期间改写、获取锁期间改写、取消及忙碌错误；Windows 专属测试覆盖真实 Unicode 写入、锁竞争、变化保护及提示窗口样式/生命周期。Windows CI 执行专属测试，Mac 只可交叉编译，不能宣称实机通过。

保留现有安装生命周期保护，不绕过 EXE/MSI 升级协调器。能在本机生成的产物与必须 Windows 构建的完整安装器分别记录，不以新版本号包装旧二进制。
