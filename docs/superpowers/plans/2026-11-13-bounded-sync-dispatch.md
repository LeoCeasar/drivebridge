# 有界云端调用、公平文件调度与安全默认转换实施计划

> **For agentic workers:** 使用 subagent-driven-development 分块实施；按用户偏好，每块定向测试，最后只合跑受影响模块并做一次整体复核。

**Goal:** 请求挂起不能无限占住同步队列，大文档不垄断执行机会；普通安全 Markdown/HTML 内容能够自动写回。

**Architecture:** 保留凭据锁和每文件独占、未知写入 journal 及五分钟最新保存版本边界。CLI 调用使用包含锁等待的有限预算并确保进程回收；后台调度将每个边界捕获的任务独立排队，下一边界不等待整轮结束，大文档仅在已验证的操作之间让出机会。转换按结构识别而非全局替换，默认配置显式记录。

**Tech Stack:** Go、bbolt、官方飞书 CLI、原生 JavaScript、现有 Markdown/XML bridge。

**Spec:** 本轮用户确认实施前一轮列出的防阻塞修复与安全默认规则。

## 约束及验收

- 保存仍是本地操作，不增加前台云端检查；每五分钟捕获各文件最新代次，不上传期间产生的每一代。
- 云端调用、锁等待、取消及进程回收都有限；禁止用“只结束页面等待”冒充释放底层槽位。
- 写请求启动后超时保留未知结果，后续先回读；确认未启动的请求不得误记为云端已写入。
- 同一文件不同时写入；跨文件公平排队，周期内新文件按下一固定边界进入，无整轮等待屏障。
- 大文档让出时所有此前操作已有回读结果，后续继续原 desired journal，不丢新保存和人工草稿。
- 默认新增简单粗斜体 HTML、简单段落 HTML、缩进代码、明确普通美元/变量文本；TOML 需无损往返验证后启用。复杂样式、资源、公式、链接标题不静默删除。
- 旧 projection 1/2/3 快照解释保持稳定；结构规则固定边界，用户替换规则继续保留。

## 工作块

- [x] 调用预算与进程回收：真实 subprocess 挂起、锁等待、子进程继承管道测试；分类未启动/未知结果；大文件单独的有限传输预算。
- [x] 调度：三个慢文件之后健康文件最终完成、旧轮慢任务与下一边界新文件并行、同文件去重与最新保存代次、长文档分片让出。
- [x] 转换与配置：安全格式的 Encode/Decode/Plan/Verify 往返；恶意属性/失配标签/代码及元信息保护；对应默认规则与 UI 友好名称。
- [ ] 整体：受影响 Go 包、JS、race、Windows 交叉编译；原生飞书临时文档验证；安装本机并保留已有数据；提交推送。

## 重点验证

取消后迟到写入不能被再次并发发送；共享凭据锁只在进程回收后释放；缺少读回的 mutation 不被清空；五分钟边界与分片恢复不混入新的保存代次；后台刷新/目录任务也不能以无限请求挡住文件。
