# 合并前字符串转换实施

用户要求：由可追加 JSON 的 source/target 规则自动处理 br 等格式差异，再合并及写回。现有规则仅作用于 XML 编码，需补齐合并前规范化及普通字符串匹配。

方案：沿用 AST 和不可变规则集；NormalizeForMerge 只在后台处理副本，转换 RawHTML token 与显式 literal 规则匹配的普通文本，排除代码、链接、图片、转义和富 HTML。同一输入片段只转换一次，目标不递归替换。默认段落 br 输出 Markdown 硬换行，表格为分隔文本；不改已保存原文及检查点。代码中的 br 保留。当前实际只确认三种 br 写法，默认通配规则兼容大小写，不默认移除其他字符。

旧冲突只在原文相同或规范化后草稿与本地完全相同时自动恢复；事务内再次比较原冲突、代际和操作日志。正文实质不同仍保护；collection.md 当前四份内容均无 br，不自动当作格式问题消除。
