# 错误提示中的内容位置

用户要求：错误提示说明是哪部分、哪些文字导致失败。沿用已有诊断持久化和错误卡片，扩展重复块映射错误的多个相关位置。

设计：SyncDiagnostic 增加 locations（side、kind、line、end_line、text、section）与 location_count。诊断仅使用当次规划失败的不可变云端投影或待上传合并稿，不读取当前编辑器正文来猜行号。重复内容仅作为定位线索，文字本身不一定有误。最多显示 8 处、每处 240 字符/4 行；无法可靠定位时保留原因而不编造位置。保留已有 HTML/受保护内容的单位置诊断。界面明确来源、章节、行范围，使用 textContent 展示原文。此任务不修改映射算法、转换模板或文档内容。

方法选择：继续现有结构化诊断链路；错误字符串拼接无法支持多位置及来源区分，状态轮询重新解析当前文件会混淆版本和增加重复工作。诊断在失败时生成、随任务保存，重启后保留。

步骤：

- [x] 实现多位置诊断及卡片展示，保留未知/无可靠位置时的行为。
- [x] 跑相关 Go、竞态和全部 UI 脚本，独立审阅一次并修复发现。
- [x] 构建并通过维护租约更新本机，正常重试原任务以生成新诊断；核验界面数据及本地内容保留。
