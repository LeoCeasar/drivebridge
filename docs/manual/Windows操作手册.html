操作顺序

    本页以 Windows 11 x64 为操作环境，使用未签名便携包完成验收。macOS 结果见 macOS 手册；Linux 未做实机验收。

    开始前

    准备自己的飞书账号、可访问的共享文件夹，以及当前用户可写的本机挂载位置。管理页使用本机浏览器；同步由独立的后台 Worker 进程运行，命令行示例默认使用 PowerShell 7（Windows PowerShell 5.1 也可运行，部分 .NET 行为不同，见“遇到问题时”）。

    本页记录开发版状态。只有包含桌面托盘、WinFsp 挂载引擎与 WebView2 登录组件的完整 Windows x64 桌面包，才能走完本手册。纯 CLI 包、--headless 预览或没有 WinFsp 的环境，均不能算作完整桌面客户端验收。本轮使用未签名便携包（r6 首轮验收，r7 修复后复测）；MSI 已构建但未安装。

    新建 .md 默认上传为飞书原生文档并投影为本地 Markdown，可使用三方合并；既有普通 .md 文件走普通文件路径，自带基准三方合并。其他普通文件发生并发修改时保留冲突副本。WinFsp 目录挂载要求父目录存在、末级目录不存在；不要把挂载点放在已有内容的目录上。先在共享空间中新建一个专用测试文件夹。测试只放新建的文本、Markdown 和子目录；不要使用已有业务资料。手册中的文件名和内容是可自行创建的测试样例。

    已验证 有本轮执行证据部分验证 尚有条件未满足或发现缺陷受阻 已发现阻塞未执行 无实际操作证据

    Windows 原生登录验收状态

    Windows 正式接入使用应用自有的 WebView2 登录窗口（随包登录组件，需要 Microsoft Edge WebView2 Runtime），不要求浏览器扩展，也不读取日常浏览器 Cookie。本轮在便携包中验证：官方页面登录、账号核验、可见共享目录发现、关闭窗口后继续扫描，以及桌面与登录组件重启后复用会话。

    尚未验证：MSI 安装后的登录入口、Windows 注销或重启后的会话复用、双真实账号隔离、有隐藏共享入口账号的目录增减、企业 SSO 变体。登录窗口只承担登录与目录发现，不承诺整站浏览兼容。

    其他平台参考

    下表来自当前项目说明与本轮实测，不能代替在对应操作系统上的安装、驱动和同步验证。

    平台桌面入口与运行条件本手册覆盖
    Windows x64无控制台桌面 EXE（bin\drivebridge-desktop.exe）与用户快捷方式；挂载需要 WinFsp（支持自定义安装路径）；应用内登录需要 WebView2 Runtime。登录自启动使用当前用户的交互式计划任务。MSI 为当前用户安装，默认位置 %LOCALAPPDATA%\Programs\DriveBridge。便携包本轮实机验收；MSI、自启动待测
    macOSDriveBridge.app 菜单栏入口；完整挂载需要 macFUSE；应用内原生登录要求 macOS 14 或更新版本。见 macOS 手册
    Linux桌面入口或 launch-desktop.sh；挂载需要 FUSE3。原生托盘还需要 GTK3、GIO、Ayatana AppIndicator 及可用的桌面托盘服务；应用内原生网页登录当前不可用。未做 Linux 实机验收

    本机常用位置：用户配置 %APPDATA%\DriveBridge\config.json；运行状态、Store、VFS 缓存与 Worker 日志 %LOCALAPPDATA%\DriveBridge\State（每个挂载的日志在 mounts\<mount_id>\logs）。便携包与 MSI 共用同一份当前用户配置和状态。

    步骤本轮状态实际观察

    截图只展示实际截取的界面。没有执行、没有截图或截图文件缺失时，本页会直接标明。截图已遮盖授权二维码、短期授权链接、账号与目录标识及企业地址；不保存密码、令牌或凭据。

    移除挂载与后台拉取过滤

    在“文件与同步”点击对应项的“停止同步”可暂时停用；点击“移除挂载”可从常规列表移除该配置。移除不会删除飞书文件，会保留本机缓存、待上传任务和冲突副本，盘符或目录挂载点随之释放。打开“已移除挂载（本机数据保留）”可恢复配置，恢复后仍保持停止，需另行点击“启动挂载”。

    在“账号与目录”展开“后台拉取过滤（可选）”，选择挂载并编辑后缀输入框，默认 .log, .db，可追加 .sqlite 等后缀。以逗号、空格或分号分隔，留空保存表示不排除。保存后无需重启挂载。

    过滤仅阻止后台拉取正文。文件名保持可见，显式打开、Get-Content 或 Select-String 可按需下载，本地新增与修改仍会上传。内容搜索首次读取会下载整文件，大量搜索会消耗带宽和缓存；搜索未上传的修改时读取本机内容，不代表云端已确认。

    # 只在专用测试目录内搜索，避免一次下载整个账号盘
Get-ChildItem -LiteralPath $ApprovedTestFolder -Recurse -File | Select-String -Pattern 'local-v2'

    本轮在独立 X: 盘验证：移除后盘符释放，11 个缓存文件共 2889 字节保留；恢复配置后保持停止，显式启动后重新可读。临时把 .txt 加入过滤后，显式读取仍得到完整正文，结束后已恢复原规则。

    普通 Markdown 的自动合并

    普通云盘 .md 文件（包括大写 .MD）支持三方同步，无需另行开启。系统保留上次确认同步的基准：仅本地变化时上传本地；仅云端变化时更新本地；双方改动相同则确认；双方修改不同位置时自动合并。

    双方修改重叠且不一致时，保留基准、本地、云端三份内容，进入“冲突与合并”。在 diff 页面核对、编辑并提交；如果提交前云端或本地又变化，草稿保留，需要刷新后重新确认。提交被接受表示排队同步，云端回读核验完成后才显示已确认。

    非 Markdown 文件继续使用覆盖方式。自动合并与文本编辑限有效 UTF-8、无 NUL、每份正文及合并结果不超过 10 MiB；保留 CRLF 与末尾换行状态，复杂差异保守保留冲突。飞书接口没有原子条件写入能力，仍存在短暂竞争窗口。

    Windows 上普通 Markdown 三方合并、重读云端版本和草稿保护的回归测试通过；本轮真实云端冲突使用的是飞书原生文档投影，没有对普通 Markdown 做真实飞书双向冲突。

    开启或关闭隐藏共享文件夹同步

    此开关针对飞书中被隐藏的共享文件夹，不是 Windows 中带“隐藏”属性的本地文件夹。默认开启，每个账号独立保存。

    操作步骤

    1. 从任务栏通知区域的 DriveBridge 托盘菜单打开管理页，进入“账号与目录”。
    2. 在“已授权账号”下拉框中选择需要设置的账号；切换账号后，开关显示该账号自己的设置。
    3. 找到“同步飞书中隐藏的共享文件夹”：勾选为开启，取消勾选为关闭。修改会自动保存，无需另点保存按钮，也不需要重新登录或重新挂载。
    4. 等待页面显示“已开启隐藏共享同步”或“已关闭隐藏共享同步”。关闭后，“隐藏共享”来源显示“已暂停同步（保留清单）”。
    5. 需要恢复时，重新勾选同一开关。已知目录恢复原路径，保留的待上传任务继续处理；新出现的目录入口由后续扫描发现，也可点击“重新扫描”更新。

    开关会影响什么

    设置账号盘中的行为
    开启（默认）包含隐藏共享入口，按需读取文件并处理后台同步。
    关闭仅从隐藏共享来源发现的目录会从账号盘隐藏，暂停后续目录扫描、正文刷新及新上传、重命名或删除任务；本机缓存、待上传内容、冲突和草稿保留。

    个人、可见共享及手动添加等明确入口仍可同步；单独创建的其他挂载不受此开关影响。

    关闭不是删除云端文件，也不是撤销访问权限。已开始的请求可能完成，正在打开或仍有本机写入的文件可能暂时保留显示（资源管理器窗口停留在该目录时尤其明显）。保留清单不代表这些入口正在同步。

    本机已验证取消勾选与重新开启都能保存并给出反馈，测试后恢复默认开启。本次账号的隐藏共享来源为 0 项，因此目录增减行为没有实际可观察对象，待有隐藏入口的账号复测。

    遇到问题时

    WinFsp 已安装，诊断仍提示驱动缺失

    WinFsp 的安装目录记录在 32 位注册表视图 HKLM\SOFTWARE\WOW6432Node\WinFsp 的 InstallDir。本版已按该视图识别自定义安装路径（如 D:\Work\WinFsp）。若仍失败，用下面命令确认记录与 bin\winfsp-x64.dll 均存在，必要时用 WinFsp 安装包修复安装。

    Get-ItemProperty 'HKLM:\SOFTWARE\WOW6432Node\WinFsp' | Select-Object InstallDir
& $DriveBridge feishu doctor --json
    启动后没有托盘图标

    Windows 默认把新图标收进通知区域溢出菜单：点击任务栏右下角的 ^ 查看，可拖到任务栏常驻，或在“设置 → 个性化 → 任务栏 → 其他系统托盘图标”中打开 DriveBridge。确认运行的是 drivebridge-desktop.exe 完整桌面包，且在当前用户的交互式桌面中启动。能够打开管理页，只能证明本机服务可用；请另行确认图标可见以及菜单可以点击。

    管理页提示本机会话失效

    管理页入口使用短期、一次性的本机引导凭证；桌面进程重启后，旧标签页会话失效。不要从浏览器历史打开旧地址，从托盘“打开管理页”或运行 & $DriveBridge desktop start 重新打开新标签页。

    挂载失败或目录看起来是空的

    查看管理页中的挂载状态、账号权限和共享文件夹标识，再确认 WinFsp 可用。目录挂载点的父目录必须存在、末级目录必须不存在（由 WinFsp 创建）；盘符挂载点不能已被占用。配置已保存并不表示已经挂载。

    资源管理器里文件显示 0 KB

    尚未下载正文的占位文件在列表中显示 0 KB，这不代表文件为空。r7 起，第一次打开时会先下载正文，程序拿到的是真实大小和完整内容；r6 及更早版本中，按长度读取的程序（如 Windows PowerShell 5.1 的 [IO.File]::ReadAllBytes）第一次可能读到空内容（问题报告第 13 项）。删除或移动冷文件同样会先下载正文；网络不可用、下载失败时，该文件暂时不能删除或改名，恢复后重试即可。

    文件已保存，但云端还没有更新

    分别查看“本机保存”和“云端状态”。等待同步、正在上传、等待回读核验、离线和冲突都没有完成云端确认。保留本地数据，检查网络与授权，在挂载运行时按“重试同步”重新核验；也可用 & $DriveBridge feishu upload status $MountId --json 查看待处理项。

    授权二维码过期，再点授权没有进展

    r7 起再次点击“授权”即可：管理页会核对已保存的授权，未完成则发出新链接，已在浏览器完成则直接继续登录，不会新建账号或丢弃待上传数据。如果核对失败，页面会显示原因和“重试”按钮。旧版本（r6）请用随包 CLI 接续：保持终端运行，在本机打开它给出的链接完成授权。命令可能显示短期授权链接，不要截图或转发。

    & $DriveBridge feishu account login --profile '管理页显示的账号名称'
    应用登录窗口提示缺少 WebView2

    安装 Microsoft Edge WebView2 Evergreen x64 运行时后，从管理页重新打开登录窗口。WebView2 工具窗口不出现在任务栏；关闭窗口可能只是隐藏，从管理页再次打开即可。

    安全停止没有立即完成

    关闭正在编辑的文件，以及停留在挂载目录中的资源管理器窗口和终端（它们会占用目录句柄），等后台处理待上传内容。安全停止可能因为打开文件、待同步内容或超时而未完成；先确认挂载路径是否已物理消失，再查看界面原因。有待保存数据时不要清缓存或直接结束 Worker 进程。
