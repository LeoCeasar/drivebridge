操作顺序

    本页以 macOS 为主要操作环境。Windows 与 Linux 的说明仅供参考，未完成对应平台的实机验收。

    开始前

    准备自己的飞书账号、可访问的共享文件夹，以及当前用户可写的本机挂载位置。管理页使用本机浏览器；同步由独立的后台进程运行。

    本页记录开发版状态。只有包含桌面托盘与挂载能力的完整安装包，才能走完本手册。纯 CLI 包、无托盘模式或没有挂载驱动的预览，均不能算作完整桌面客户端验收。

    先在共享空间中新建一个专用测试文件夹。测试只放新建的文本、Markdown 和子目录；不要使用已有业务资料。手册中的文件名和内容是可自行创建的测试样例。

    遇到问题时

    启动后没有托盘图标

    确认使用包含原生托盘的完整桌面包，并在当前用户的图形桌面中运行。Linux 还需要可用的桌面托盘服务。能够打开管理页，只能证明本机服务可用；请另行确认图标可见以及菜单可以点击。

    挂载失败或目录看起来是空的

    查看管理页中的挂载状态、账号权限和共享文件夹标识，再确认当前系统驱动已安装并可用。配置已保存并不表示已经挂载。驱动安装或系统许可失败时，应先解决运行条件。

    文件已保存，但云端还没有更新

    分别查看“本机保存”和“云端状态”。等待同步、正在上传、等待回读核验、离线和冲突都没有完成云端确认。保留本地数据，检查网络与授权，在挂载运行时按“重试同步”重新核验。

    授权过期或账号权限发生变化

    在“账号与目录”查看账号状态。恢复已有账号时，使用界面提供的“停止相关挂载并重新授权，保留待上传数据”，并以原身份完成授权。授权后继续核对待处理项目和云端结果。

    安全停止没有立即完成

    关闭正在编辑的文件，等后台处理待上传内容。安全停止可能因为打开文件、待同步内容或超时而未完成；保留缓存与恢复数据，查看界面原因，再尝试停止。
